## Interpretation rules

- Impressions, likes and followers are not equivalent to trust, demand or revenue.
- Compare similar periods and note changes in posting volume.
- Platform metrics have different definitions; do not combine them without explaining the method.
- Track audience relevance: AIML students/builders, founders/operators, recruiters/mentors and potential buyers for a validated offer.
- Use aggregated analytics wherever possible; do not collect unnecessary personal data about followers.
- Record detailed inquiries only in the appropriate internal CR sales system. Keep this public-facing tracker aggregated.
- Attribution is uncertain unless a source or referral path confirms it.

## Monthly decisions

Which audience segment grew? Which content created relevant conversations? Did the website help people inspect real work? Which channel deserves continued effort? What should be paused because it produces low-quality attention?

A follower increase is an audience signal, not proof of customer demand.
