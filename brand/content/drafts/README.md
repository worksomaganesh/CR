# Draft Content

Store unpublished founder-brand drafts here.

Suggested filename: YYYY-MM-DD-short-topic.md

Each draft should include:
- Status: draft / review / approved / rejected.
- Primary audience and platform.
- Content pillar and intended takeaway.
- Source or project evidence links.
- Draft copy and optional media notes.
- Factual, privacy and rights checks.
- Founder approval date and final published URL when applicable.

Do not store confidential customer material, private messages, credentials or unredacted business documents here.
