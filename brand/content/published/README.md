# Published Content Index

Record only content that is live and accessible. Keep unpublished drafts in ../drafts/.

Suggested filename: YYYY-MM-DD-short-topic.md

For each publication, record:
- Exact live URL and platform.
- Publication date and time.
- Approved final copy or durable archived reference.
- Evidence links supporting factual claims.
- Any correction or update made later.
- Performance review date and useful outcome.

A scheduled post is not published. Do not add an entry until the live post can be verified.
