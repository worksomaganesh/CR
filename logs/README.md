# Chronological journey log

Use one dated entry per meaningful work session. Include:
- Goal and context
- Sources/tools used
- Actions performed
- What changed (files, assumptions, product, outreach)
- Evidence and links
- Problems, failed attempts and fixes
- Lessons learned
- Decisions and why
- Next steps
- Time and cost, when useful

Do not claim a task was completed unless it was actually performed. Distinguish planned work from completed work. Keep sensitive customer data and credentials out of the repository.
